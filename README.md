# 音蔵（iPhone 版）

自分の曲を入れて、歌詞をカラオケ風に表示する音楽プレーヤー。iPhone の Safari で動く Web アプリです。

**https://shiro-utouto.github.io/otokura-web/**

## 使い方

1. iPhone の Safari で上のページを開く
2. 下の「共有」ボタン →「ホーム画面に追加」
3. ホーム画面の「音蔵」を開き、右上の ＋ から「ファイル」アプリにある曲（mp3・m4a・mp4 など）を選ぶ
   - 同じ名前の `.lrc` を一緒に選ぶと、それが歌詞になります
   - 歌詞がない曲は、曲名・アーティスト・長さで [LRCLIB](https://lrclib.net) から自動で探します

曲・歌詞・プレイリストは iPhone の中だけに保存され、どこにも送られません。ときどき「設定」→「バックアップ」で zip を保存しておくと安心です。
